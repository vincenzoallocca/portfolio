### Conseguenze

1. **Obiettivo primario invariato: le ricerche sul nome.** Le keyword generiche non hanno
   un intento compatibile con un portfolio personale e un dominio giovane.
2. **Disambiguazione dall'omonimo.** Aggiunta `disambiguatingDescription` al `Person`
   (sviluppatore, studente di Ingegneria Informatica dal 2026, fondatore di HASTE, sito
   ufficiale). Nel testo visibile i descrittori distintivi (studente, sviluppatore, HASTE)
   erano già presenti. Usare sempre gli stessi descrittori su GitHub, Instagram e haste.it.
3. **Le leve più forti sono esterne al sito:**
   - verifica in Search Console e Ispezione URL, per capire se le pagine sono indicizzate;
   - link da haste.it al portfolio (oggi assente) e campo Website di GitHub (oggi 404);
   - nome completo "Vincenzo Allocca" sul profilo GitHub (oggi solo "Vincenzo").
4. Ripetere le stesse 6 SERP **4–6 settimane dopo** questi interventi (circa 30 crediti) per
   misurare l'effetto.
